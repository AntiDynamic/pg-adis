## Component Visual Patterns

### Badge Styles
```
┌─────────────────┐  ┌─────────────────┐  ┌─────────────────┐
│ [✓] Verified    │  │ [★] Premium     │  │ [•] New         │
│ (Green glow)    │  │ (Amber glow)    │  │ (Blue glow)     │
└─────────────────┘  └─────────────────┘  └─────────────────┘
```

### Button Variants
```
┌──────────────┐  ┌──────────────┐  ┌──────────────┐
│   Primary    │  │  Secondary   │  │   Outline    │
│ (Green fill) │  │ (Gray fill)  │  │(Green border)│
└──────────────┘  └──────────────┘  └──────────────┘
```

### Card States
```
Default:                  Hover:
┌─────────────┐          ┌─────────────┐
│             │          │     ↑ -4px  │ (Lifted)
│   Content   │    →     │   Content   │
│             │          │  (Shadow↑)  │
└─────────────┘          └─────────────┘
```

### Rating Display
```
★★★★☆ 4.7
(Filled: #22c55e | Empty: #374151)
```

## Spacing Visual Guide

### Component Padding
```
Small:   │ 16px │ Content │ 16px │ (p-4)
Medium:  │  24px  │ Content │  24px  │ (p-6)
Large:   │   32px   │ Content │   32px   │ (p-8)
```

### Grid Gaps
```
Tight:   Card │ 12px │ Card │ 12px │ Card  (gap-3)
Normal:  Card │ 16px │ Card │ 16px │ Card  (gap-4)
Loose:   Card │ 24px │ Card │ 24px │ Card  (gap-6)
```
